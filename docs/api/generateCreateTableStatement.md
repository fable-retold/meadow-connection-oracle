# generateCreateTableStatement(pMeadowTableSchema)

Generates a single Oracle `CREATE TABLE` statement (no terminator) from a Meadow table schema object. Delegated to the schema provider. For the full set of statements needed on legacy Oracle (sequence + trigger), use `generateCreateTableStatements()` (plural) or `createTable()`.

## Signature

```javascript
generateCreateTableStatement(pMeadowTableSchema)
```

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `pMeadowTableSchema` | object | Yes | Schema with `TableName` (string) and `Columns` (array) |

### Schema Object Format

```javascript
{
	TableName: 'FableTest',
	Columns:
	[
		{ Column: 'IDFableTest',   DataType: 'ID' },
		{ Column: 'GUIDFableTest', DataType: 'GUID' },
		{ Column: 'Title',         DataType: 'String', Size: '256' },
		{ Column: 'Description',   DataType: 'Text' },
		{ Column: 'IDAuthor',      DataType: 'ForeignKey' }
	]
}
```

### Column Object Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `Column` | string | Yes | The column name |
| `DataType` | string | Yes | One of: `ID`, `GUID`, `ForeignKey`, `Numeric`, `Decimal`, `String`, `Text`, `DateTime`, `Boolean`, `JSON`, `JSONProxy` |
| `Size` | number or string | Varies | Required for `String`, `Decimal`; optional for `GUID` (defaults to 255) |
| `StorageColumn` | string | For `JSONProxy` | The physical column name used for a `JSONProxy` |

## Return Value

A string containing the `CREATE TABLE` statement (no trailing semicolon).

## Type Mapping

| Meadow DataType | Oracle Output | Default | Notes |
|-----------------|---------------|---------|-------|
| `ID` | `NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | -- | Legacy mode: `NUMBER PRIMARY KEY` (sequence + trigger added separately) |
| `GUID` | `VARCHAR2(Size) ... NOT NULL` | `'00000000-0000-0000-0000-000000000000'` | Size defaults to 255 |
| `ForeignKey` | `NUMBER ... NOT NULL` | `0` | |
| `Numeric` | `NUMBER ... NOT NULL` | `0` | |
| `Decimal` | `NUMBER(Size)` | -- | Size is the precision spec |
| `String` | `VARCHAR2(Size)` | `' '` | Nullable (Oracle treats `''` as NULL) |
| `Text` | `CLOB` | -- | |
| `DateTime` | `TIMESTAMP` | -- | |
| `Boolean` | `NUMBER(1)` | `0` | |
| `JSON` | `CLOB` | -- | |
| `JSONProxy` | `CLOB` | -- | Uses `StorageColumn` |

Columns whose `DataType` is not recognized are skipped.

## Basic Usage

```javascript
let tmpSchema =
{
	TableName: 'FableTest',
	Columns:
	[
		{ Column: 'IDFableTest',   DataType: 'ID' },
		{ Column: 'GUIDFableTest', DataType: 'GUID' },
		{ Column: 'Title',         DataType: 'String', Size: '256' },
		{ Column: 'Description',   DataType: 'Text' },
		{ Column: 'IDAuthor',      DataType: 'ForeignKey' }
	]
};

let tmpSQL = _Fable.MeadowOracleProvider.generateCreateTableStatement(tmpSchema);
console.log(tmpSQL);
```

On a modern (12c+) connection in the default unquoted mode this produces:

```sql
CREATE TABLE FableTest
    (
        IDFableTest NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        GUIDFableTest VARCHAR2(255) DEFAULT '00000000-0000-0000-0000-000000000000' NOT NULL,
        Title VARCHAR2(256) DEFAULT ' ',
        Description CLOB,
        IDAuthor NUMBER DEFAULT 0 NOT NULL
    )
```

## Quoted Identifiers

With `Oracle.QuoteIdentifiers: true`, identifiers are wrapped in double quotes to preserve case:

```sql
CREATE TABLE "FableTest"
    (
        "IDFableTest" NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        "Title" VARCHAR2(256) DEFAULT ' ',
        ...
```

## Legacy Identity

This method always emits the 12c+ identity column. To get the legacy `NUMBER PRIMARY KEY` plus its sequence and trigger, use `generateCreateTableStatements()`:

```javascript
// LegacyIdentity resolved to true (11g) -> three statements
let tmpStatements = _Fable.MeadowOracleProvider.generateCreateTableStatements(tmpSchema);
// [ CREATE TABLE ..., CREATE SEQUENCE SEQ_FableTest ..., CREATE OR REPLACE TRIGGER TRG_FableTest ... ]
```
